# Intro to Computer Vision Capstone Project: Image Style Transfer

## Repo Contents
* code: folder with preliminary development jupyter notebooks
  * Final_Implementations: folder with final jupyter notebooks
  * dataset\images: folder with subject images (portraits, landscape, still-life)
  * dataset\modern: folder with modern style images
  * dataset\monet: folder with Monet style images
  * dataset\photorealistic: folder with photorealistic style images
  * dataset\picasso: folder with Picasso style images
  * dataset\seurat: folder with Seurat style images
  * dataset\vangogh: folder with van Gogh style images 
* presentation: folder with final presentation associated with project
